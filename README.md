# Pharmaceutical QC Dashboard

Excel dashboard project focused on pharmaceutical quality control trend analysis and OOS (Out of Specification) investigation workflows.

## Project Features
- Pivot tables
- Interactive slicers
- QC trend analysis
- Pass/Fail tracking
- Laboratory-style structured dataset
- Dashboard visualization

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- Data Cleaning

## Project Goal
Analyze laboratory QC performance data across products, analysts, and instruments to identify trends and support quality investigations.
